# Kinetic Architecture Pack

Ten animation languages for the ten Dreamscapes worlds. The pack changes runtime Hyprland animation leaves only; it does not rewrite `~/.config/hypr/looknfeel.lua`.

Examples include sonar-like pop-ins for Abyssal Cartographer, clinical slides for Dream Bureaucracy, ink-like fades for Living Ink, and vertical elevator motion for The Impossible Hotel.

## Install

```bash
./expansion-packs/kinetic-architecture/install
```

The active profile reapplies on boot and after every theme change.

## Commands

```bash
dreamscapes-kinetic status
dreamscapes-kinetic apply
dreamscapes-kinetic restore
```

## Remove

```bash
./expansion-packs/kinetic-architecture/uninstall
```

Removal restores Omarchy's current default animation values.
